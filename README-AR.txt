تطبيق Anas Print Comptabilité - مشروع Android

محتويات المشروع:
- تطبيق Android مبني على WebView ويضم أداة المحاسبة.
- أيقونة دائرية مأخوذة من شعار ANAS PRINT الذي أرسلته.
- تخزين البيانات محلياً داخل التطبيق عبر localStorage.
- استيراد نسخة JSON من الهاتف.
- تصدير نسخة JSON عبر نافذة حفظ الملفات في Android.

طريقة استخراج APK:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2) افتح تبويب Actions في المستودع.
3) شغّل سير العمل "Build Android APK" (أو انتظر انتهاء البناء بعد push).
4) افتح نتيجة التشغيل ثم Artifacts وحمّل Anas-Print-Android-APK.
5) فك الضغط وثبّت app-debug.apk على هاتف Android.

ملاحظة مهمة:
هذا مشروع Android جاهز للبناء، وليس ملف APK مبنياً بالفعل. يتطلب إخراج APK بيئة بناء Android/Gradle متصلة.
البيانات تحفظ على نفس تثبيت التطبيق والهاتف. احتفظ بنسخة JSON دورياً، ولا تحذف بيانات التطبيق قبل تصدير النسخة الاحتياطية.
